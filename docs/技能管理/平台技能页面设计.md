## 技能箱->平台技能->相关按钮功能设计
当前数据交互以mock 数据模拟,后续再进行实际api开发
- 1. 删除技能存在两种情况需要判断,1.该技能存在关联会话,实际api通过调用数据库查询获取数据返回判断,2.该技能不存在关联会话则直接提示确认是否删除,当用户点击确认后删除该技能
- 2. 点击 "装载技能" 后会弹出一个页面框,需要用户选择装载的关联会话,如果用户下面没有任何会话则显示未空且不可进行装载,如果用户下面存在会话则下拉列表选择对应会话后点击确认进行装载技能,同时在我的技能就可以看到对应的装载技能信息
- 3. 点击 "查看详情" 可以查看该技能的详情信息,技能详情 页面信息可以参考 @docs/database_design/skills.sql 表相关信息进行设计


## 技能箱->新建技能页面功能开发

- 1.点击 "新建技能" 弹出新建技能页面,页面信息可以参考 @docs/database_design/skills.sql 表相关信息进行设计
- 2.注意: file_path 并不是让用户填写技能路径, 而是提供上传文件功能只支持 .zip 格式的压缩包 让用户上传技能压缩包,平台存储后记录压缩包存放路径,然后写 skills 表的时候将 file_path 字段填写上传压缩包的路径
- 3. icon 是提供图标库给用户选择,选择后记录icon的值, 基于 TailwindCSS 图标库

- 4. 平台技能卡片更多选项中新增"启用","禁用" 按钮, 当用户点击"启用"按钮后,技能状态更新为"已启用",当用户点击"禁用"按钮后,技能状态更新为"已禁用", 如果技能状态"已禁用"则显示"启用"按钮,否则显示"禁用"按钮
- 5. 如果当前已启用的技能有关联会话装载此技能则点击 "禁用" 提示当前技能存在关联会话,禁用将导致所有加载该技能的会话无法使用该技能,请确认是否禁用
