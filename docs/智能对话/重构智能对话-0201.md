协作式开发
多个实例可以同时访问同一个项目的会话历史
便于在不同终端/端口间切换工作
共享 Agent、模型配置等资源



- 新建 `chat_servers` 表 ,用于存储启动的opencode server 信息,主要包含以下字段:
    - id: 自增列id
    - chat_id: uuid, 对话启动的server id
    - proxy_id: 关联 proxy_host 表中的 id
    - host: 启动的服务ip
    - port: 启动的服务端口
    - chat_dir: 在哪个目录下启动的opencode server
    - status: 是否可用的状态, active ,disable,默认 active
    - created_at: 创建时间
    - created_by: 创建人, 关联users 表中的 id

- 新建 `proxy_host` 表,用于存储部署了 proxy 的服务器信息, 这些服务器可以用于通过 编写的 proxy程序启动opencode server
    - id: 自增列id
    - host: 服务器ip
    - port: 服务器端口
    - default_chat_port: 默认对话开始端口,如果 chat_servers 对应 proxy 没有任何一条记录则以这个port定义为起始端口定义
    - status: 是否可用的状态, active ,disable,默认 active
    - created_at: 创建时间
    - created_by: 创建人, 关联users 表中的 uuid
