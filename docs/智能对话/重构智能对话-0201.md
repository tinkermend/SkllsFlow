## 智能服务 添加服务前后端实现逻辑

点击添加按钮,弹出请需要创建的智能服务名称,最长16个字符,输入后点确认调用后端 nodejs api,后端实现如下逻辑
- 1. 数据库查询 SELECT id,host,port, begin_chat_port FROM proxy_host where status='active' order by  updated_at asc  limit 1 , 如果有返回数据条目则存储数据并进行下一步逻辑,如果没有则返回"无可用的代理服务,请添加代理服务"到前端
- 2. 获取 .env 中的 OPENCODE_BASE_PATH,PROXY_API_SECRET,OPENCODE_AUTH,OPENCODE_PASSWORD 变量值
- 3. 通过上一个sql 获取的id 值 查询 chat_servers 表: SELECT port FROM chat_servers  where proxy_id={id} and status='active' order by created_at desc limit 1 ,如果返回的数据为空 则以 proxy_host 表中的begin_chat_port作为调用 proxy request port 参数, 否则 则以 chat_servers 返回的 port +1 作为 request 的port变量
- 4. 生成一个 由 用户名 + 随机6位字符串的 变量 与 OPENCODE_BASE_PATH 拼接为新的变量,假设变量定义为 ChatServerDir=OPENCODE_BASE_PATH+"/"+username+random6
- 5. 后端api 构造调用 proxy 服务的 http 请求:

---request
curl -X POST http://{proxy_host表返回的host}:{port}/api/opencode_start \
  -H "Content-Type: application/json" \
  -H "X-Signature: {PROXY_API_SECRET}" \
  -d '{
    "port": {port},
    "auth": {OPENCODE_AUTH},
    "auth_password": {OPENCODE_PASSWORD},
    "chat_dir": "{ChatServerDir}"
  }'

---response  
{"code":200,"message":"服务启动成功"}
- 6. 调用proxy http api 服务 所有code 非200 的都是失败,失败将message 返回到前端
- 7. 如果返回code 为200 则将返回的port 等信息存储到 chat_servers 表中,并返回"服务启动成功"到前端


**备注**

- chat_servers 中存储的 name 为用户输入的智能服务名称
- error_message 列是另外一个后台程序定时检查opencode 服务如果有错误写入的, 当前新增不需要写入



## 前端布局调整

**任务目标：**
重构智能对话页面中现有的侧边栏（SessionSidebar）组件，将其布局从单一列表改为“上下分栏”结构。

**技术栈要求：**
- 组件库：shadcn/ui
- 样式库：Tailwind CSS V4
- 图标库：Lucide React 

**具体布局与样式修改要求：**

1.  **整体容器布局 (Main Container):**
    - 将侧边栏的最外层容器修改为 Flex 纵向布局 (`flex flex-col h-full`)。
    - 确保侧边栏高度占满父容器，且宽度保持不变。

2.  **上半部分：智能服务:**
    - **位置：** 位于侧边栏顶部。
    - **布局行为：** 高度根据内容自适应（`flex-none`），或者设置一个最大高度限制（如 `max-h-[40%]`），防止占用过多空间。
    - **标题栏：**
        - 左侧显示标题文本 "智能服务"（搭配一个 Bot 图标）。
        - 右侧显示一个 "添加" 按钮（`+` icon），样式使用 `variant="ghost"` 的 icon button。
    - **内容区：** 用于展示服务列表的区域，以最多显示5行数据定义高度。

3.  **中部：分割线 (Separator):**
    - 在上半部分和下半部分之间，插入一个 shadcn/ui 的 `<Separator />` 组件。
    - 设置适当的上下 Margin (`my-2`) 以保持视觉呼吸感。

4.  **下半部分：对话列表区 (Chat List):**
    - **位置：** 位于分割线下方。
    - **布局行为：** 必须占据侧边栏剩余的所有垂直空间（关键样式：`flex-1 min-h-0`）。
    - **标题栏：**
        - 左侧显示标题文本 "对话列表"（搭配 Message 图标）。
        - 右侧显示一个 "新建对话" 按钮（`+` icon），样式同上。
5.  **视觉细节：**
    - 保持与当前设计一致的 Padding、字体大小和颜色规范。
    - 两个区域的标题栏样式应保持一致（字号、颜色、对齐方式）。
