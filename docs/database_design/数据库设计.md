# AIOps平台数据库表设计

`数据库类型`: PostgreSQL
`数据库版本`: 16
`字符集`: UTF8
`数据库`: aiops
`数据库ip`: 127.0.0.1
`数据库端口`: 5432
`数据库用户名`: aiops
`数据库密码`: AIOps!1234

## 1.重置数据库

```bash
npx prisma migrate reset
```

## 2.手动创建函数

```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

## 3.生成迁移sql

```bash
npx prisma migrate dev --name add_missing_tables_and_comments
```

## 4.生成 Prisma Client

```bash
npx prisma generate

```

## 5.初始化数据(最后一步)

```bash
psql -U aiops -p 5432 -d aiops -h 127.0.0.1 -f seed_data.sql
```
