
# AIOps平台数据库表设计

`数据库类型`: PostgreSQL
`数据库版本`: 16
`字符集`: UTF8
`数据库`: aiops
`数据库ip`: 127.0.0.1
`数据库端口`: 5432
`数据库用户名`: aiops
`数据库密码`: AIOps!1234


docker run -d \
  --name postgres-aiops \
  -p 5432:5432 \
  -e POSTGRES_USER=aiops \
  -e POSTGRES_PASSWORD='AIOps!1234' \
  -e POSTGRES_DB=aiops \
  --restart unless-stopped \

### 关键配置选项详解
| 选项（Option） | 作用 | 取值/示例 | 备注 |
|----------------|------|-----------|------|
| Description | 描述代理功能与适用场景 | `"Reviews code for best practices and potential issues"` | **必填项** |
| Temperature | 控制 LLM 响应的随机性/创造性 | 0.1（聚焦确定）、0.7（高创造性） | 范围 0.0-1.0，无配置时用模型默认值（多数为 0，Qwen 模型为 0.55） |
| Max steps | 限制代理迭代次数，控制成本 | `"maxSteps": 5` | 达到限制后，代理会总结工作并推荐剩余任务 |
| Disable | 禁用代理 | `"disable": true` | 禁用后代理不可用 |
| Prompt | 指定自定义系统提示词文件 | `"prompt": "{file:./prompts/code-review.txt}"` | 路径相对于配置文件所在位置 |
| Model | 覆盖代理使用的模型 | `"model": "anthropic/claude-haiku-4-20250514"` | 格式为`provider/model-id`，主代理默认用全局模型，子代理默认用调用它的主代理模型 |
| Tools | 控制代理可访问的工具 | `"tools": { "write": false, "mymcp_*": false }` | 支持通配符，代理配置覆盖全局工具配置 |
| Permissions | 管理代理操作权限（edit/bash/webfetch） | `"permission": { "edit": "deny", "bash": { "git push": "ask" } }` | 取值：`ask`（需批准）、`allow`（直接允许）、`deny`（禁用），支持 glob 模式 |
| Mode | 定义代理使用模式 | `primary`（主代理）、`subagent`（子代理）、`all`（默认） | 决定代理是否可直接交互或被调用 |
| Hidden | 隐藏子代理在`@`自动补全菜单 | `"hidden": true` | 仅对子代理生效，仍可被模型通过 Task 工具调用 |
| Task permissions | 控制代理可调用的子代理 | `"permission.task": { "*": "deny", "code-reviewer": "ask" }` | 支持 glob 模式，按规则顺序匹配，最后一条生效 |
| Additional | 传递模型/服务商特定参数 | `"reasoningEffort": "high", "textVerbosity": "low"` | 需参考服务商文档，参数直接传递给模型 |
